# E-Commerce Recommendation System

## Project Description

This project implements an E-Commerce Recommendation System using Association Rule Mining (Apriori Algorithm).

The system analyzes customer transaction data and recommends products that are frequently purchased together.

## Features

- Association Rule Mining
- Apriori Algorithm
- Flask Backend
- HTML/CSS Frontend
- Product Recommendations

## Technologies Used

- Python
- Flask
- Pandas
- Mlxtend
- HTML
- CSS

## Installation

```bash
pip install -r requirements.txt
python app.py
```
